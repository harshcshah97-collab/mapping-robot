ROBOT CONTROL

What should Bob do?

One operating mode runs at a time. Switching modes safely stops the old controller first.

IDENTITY LOCK

Follow only you

Start Vision, stand alone in view, then enroll. Bob will refuse motion until a profile exists.

The current profile matches clothing colour and appearance. It is safer than nearest-person tracking, but it is not biometric proof.

BOB ASSISTANT

Ask or command

Try “Come to the kitchen”, “Follow me”, or “What do you see?”

Voice stays available through “Hi Bob”. Scene questions require the OAK-D camera feed to be running.
